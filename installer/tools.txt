# The tools shown on the installer's "What is included" page, in the order shown.
# One line per tool:  Group | Icon | Name | Description
#   Group        the ribbon panel the tool sits on (a heading is drawn each time it changes)
#   Icon         the folder under RevoBIM.Revit\Resources whose icon.png is used
#   Name         tool name
#   Description  one short line
# make-assets.ps1 turns this into the icons and the list code that RevoBIM.iss includes, so
# adding a tool is one line here (plus its button in App.cs). Lines starting with # are ignored.

Annotation|NumberSequencer|Number Sequencer|Number duct and pipe systems into a parameter you choose, branches first then on up the main, and tag them; or order every system in the view in a table and run it.
Coordination|FindInView|Find in View|Select elements, then pick the view to see them in: it opens and zooms to the selection.
Coordination|MatchOffset|Match Offset|Take the top, middle or bottom offset off one element and put the elements you click next on the same offset; Slope matches a falling pipe run.
Coordination|NudgeUp|Nudge Up|Raise selected elements by the Nudge increment (default 50mm).
Coordination|NudgeDown|Nudge Down|Lower selected elements by the Nudge increment (default 50mm).
Coordination|NudgeSettings|Nudge Settings|Set the Nudge increment and how the buttons behave.
Coordination|Align3D|3D Align|Centre one pipe, duct, cable tray or conduit on another in plan; keeps going until Escape.
Coordination|SheetNamePush|Sheet Name Push|Browse and edit sheet numbers and names, stage find/replace and prefix/suffix, and push name segments into sheet parameters.
Coordination|UnhideInView|Unhide in View|List the elements and categories hidden in each view and unhide what you tick.
Coordination|BulkRename|Bulk Rename|Find and replace, prefix or suffix across the views, sheets and families selected in the Project Browser.
Coordination|Arcade|RevoBIM Arcade|Pacman, Tetris and Snake, in its own window.
FAB Automation|HangerAutomation|Hanger Automation|Fabrication and family hangers: place, size, re-align and extend hangers on duct runs.
Management|ExcelForRevit|Excel for Revit|Edit a schedule in a spreadsheet grid, then apply it in one transaction.
Management|FilterManager|Filter Manager|Edit every view filter, see them all in a table, and push them between view templates.
Management|ModelCleanup|Model Cleanup|Save a detached copy and strip it ready to send.
Management|LegendCreator|Legend Creator|Family legends and system colour legends from the model.
Sheet Tools|ProSheetsExporter|Pro Sheets Exporter|Batch export sheets and views to PDF, DWG, NWC and IFC.
Sheet Tools|RevisionManager|Revision Manager|Add, edit, reorder and merge the project's revisions.
BWIC Tools|BwicIdPush|BWIC ID Push|Click a linked Generic Model element, then a host element: copies CLM_BWIC ID into BGL_BWIC ID; repeats until Escape.
BWIC Tools|BwicPenetration|BWIC Penetration|Wall, Slab and Global Placement tabs: place a BWIC around the services you select (or every group crossing a fire rated or blockwork wall in a link), with Family settings, preview and a resize for existing BWICs.
