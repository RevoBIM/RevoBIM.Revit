# ParaManager changelog

## 1.0.0
- First release on the Management panel. Modeless window, Revit dark and light themes, Auto follows the canvas.
- Parameters tab: every project and shared parameter with Discipline, Type, Group Under and Instance/Type. Add Parameter, Excel export and import, Batch Actions. Nothing written until Apply.
- Categories tab: assign to one or many parameters, saved category groups.
- Shared Editor tab: load, edit, duplicate, delete, New Guid, add at the bottom, groups, rename. Saved through Save As, rebuilt from the file as it came in.
- Transfer and Families tabs are placeholders.
